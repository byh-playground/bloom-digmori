# 디그모리 · Digmori

복셀 월드를 탐험하며 귀여운 생물을 키워 함께 싸우는 2.5D 액션 육성 게임입니다. 기획과 단계별 계획은 [docs/game-design.md](docs/game-design.md)가 원본입니다.

**지금 단계(0.29.0, 플레이어 슬라이스):** three.js 복셀 초원 위에서 새 플레이어(작은 탐험가 꼬마)가 걷고, 구르고, 평타 3연타를 합니다. 캐릭터는 부품 PNG를 실행 중에 조립하는 컷아웃 애니메이션이고, 장비 단계(맨손·철·청수정)는 같은 부품의 색만 바꿉니다. 이전 버전의 자체 WebGL 렌더러·Rapier 물리·옛 캐릭터와 동료는 모두 지웠고, 저장 형식도 이어받지 않습니다.

## 조작

| 동작 | 키 |
|---|---|
| 이동 | WASD / 방향키 |
| 구르기 | Space / 왼쪽 Shift |
| 공격(3연타) | J / 화면 클릭 |
| 시점 45° 회전 | Q / E |
| 무기 | 1 검 · 2 대검 · 3 창 · 4 도끼 |
| 장비 단계 | T |

## 구조

| 경로 | 역할 |
|---|---|
| `src/sim/` | 결정론 시뮬레이션. 정수만 쓴다(1 m = 1024, 30 TPS). 부동소수 리터럴·삼각함수·난수·시각 API는 E2E 정적 검사가 막는다 |
| `src/present/` | three.js 렌더러와 플레이어 리그. 시뮬레이션 상태를 읽기만 한다 |
| `src/input/`, `src/runtime/` | 키 입력 → 틱 명령, 고정 틱 루프와 시작 |
| `src/assets/player/` | 플레이어 부품 원본 PNG와 무기 손잡이 기준점 |

## 실행과 검증

```bash
npm run dev
```

브라우저에서 http://127.0.0.1:8000/bloom-digmori/ 를 엽니다. 빌드 단계는 없고 `index.html`과 `src/`를 그대로 제공합니다. three.js(0.160.0)를 CDN의 고정 ESM으로 읽으므로 오프라인 실행은 지원하지 않습니다.

```bash
npm test
```

이동·구르기·3연타·장비 교체를 실제 브라우저로 실행하고, 기록한 입력을 다시 실행해 같은 체크섬이 나오는지 확인합니다(180초 상한). main 병합 뒤 GitHub Actions가 같은 파일을 바이트 그대로 Pages에 배포합니다.
